**Key customization**:

## 🎯 By Task

### Task: Change My Name
**File**: `index.html`
**Steps**:
1. Open `index.html`
2. Search "Ashvin Mori" (use Ctrl+F)
3. Replace with your name
4. Save
5. Refresh browser

**Time**: 2 minutes ⏱️

### Task: Change Colors
**File**: `style.css`
**Steps**:
1. Open `style.css`
2. Find `:root` section (top)
3. Change `--primary-color` hex value
4. Save
5. Refresh browser → See changes!

**Time**: 1 minute ⏱️

### Task: Add a New Project
**File**: `index.html`
**Steps**:
1. Find projects section (~line 500)
2. Copy a project card
3. Update title, description, links
4. Save and refresh

**Time**: 5 minutes ⏱️

### Task: Update Skills
**File**: `index.html`
**Steps**:
1. Find skills section (~line 400)
2. Change skill name
3. Change progress percentage (width: XX%)
4. Save and refresh

**Time**: 3 minutes ⏱️

### Task: Setup Contact Form
**File**: `script.js` & Google Forms
**Steps**:
1. Create Google Form (3 questions)
2. Get submission URL
3. Update script.js with URL
4. Test form

**Time**: 10 minutes ⏱️

### Task: Deploy Website
**File**: All files
**Steps**:
1. Choose platform (GitHub/Netlify)
2. Upload files
3. Configure domain (if custom)
4. Enable HTTPS

**Time**: 5-15 minutes ⏱️
