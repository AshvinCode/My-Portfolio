## 🌐 Go Live in 2 Minutes

### Option A: GitHub Pages (FREE, EASIEST)

```bash
# 1. Create GitHub account (if you don't have one)
# 2. Create new repository: "portfolio"
# 3. Upload these files to repo
# 4. Go to Settings → Pages → Enable

# Your site: github.com/yourusername.github.io
```

### Option B: Netlify (FREE, DRAG & DROP)

```
1. Go to netlify.com
2. Drag and drop your project folder
3. Done! Your site is live!
```

### Option C: Your Own Domain

```
1. Buy domain (godaddy.com, namecheap.com)
2. Buy hosting ($3-10/month)
3. Upload files via FTP
4. Point domain to hosting
5. Done!
```

## 🎨 Change Colors (2 minutes)

## 🚀 Deploy

### GitHub Pages (Most Popular)

```bash
git init
git add .
git commit -m "Launch portfolio"
git remote add origin https://github.com/YOU/portfolio.git
git push -u origin main
```

Then go to repo → Settings → Pages → Enable

Your site is live at: `yourname.github.io/portfolio`

### Netlify (Easiest)

1. Go to netlify.com
2. Drag folder → drop
3. Done! (Get link immediately)
